# Technical debt register

Known shortcuts, fragilities and deferred work. One row per item; an item is
closed by moving it to **Closed** with the commit or ADR that resolved it, not by
deleting it. Decisions behind the items are in [`adr/`](adr/README.md).

**Priority** — P1: can show wrong data or lock people out. P2: will need a
developer when a foreseeable event happens. P3: cleanliness.

Last reviewed: 2026-10-15.
